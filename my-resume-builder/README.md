# SwiftCV Pro - Professional Resume Builder

A high-performance web application built for the 2026 Hackathon.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Modern UI Architecture), JavaScript (ES6+)
- **Backend/Database:** Supabase Cloud Storage
- **Features:** Multi-step form, Cloud Data Sync, PDF Generation

## Hackathon Requirements Fulfilled
- [x] Supabase Integration for Data Storage
- [x] Responsive Design for Mobile/Desktop
- [x] Professional UI/UX with custom branding
- [x] Ability to Create, Preview, and Download Resumes
